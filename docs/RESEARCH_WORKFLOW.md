# Research workflow

For each question:

1. Restate the scope and identify whether the claim concerns consensus, mempool/relay policy, implementation behavior, economics, or a proposal.
2. Search the library with several precise terms. Use metadata filters when the source class matters.
3. Inspect the top documents and their provenance. A synthetic fixture tests retrieval but is not evidence of a real forum or mailing-list position.
4. Use the Script evaluator only for its documented ASM/compiler and synthetic-transaction scope. Confirm the response names the pinned `rust-bitcoinkernel` backend before relying on the trace.
5. Check the attached Bitcoin Core node for any node-dependent experiment.
6. Answer with document IDs and canonical links, distinguish observations from inferences, and list missing primary evidence.

The repository intentionally starts with manifests and small original fixtures. Do not claim that it contains the full paper, Delving Bitcoin, or mailing-list corpus.
