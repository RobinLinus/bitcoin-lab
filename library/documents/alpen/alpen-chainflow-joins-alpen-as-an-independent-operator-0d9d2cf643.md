Chainflow joins Alpen as an independent operator

Expanding Alpen’s independent operator set for mainnet

Chainflow has joined Alpen as one of its first independent operators, with the goal of securing BTC deposits and withdrawals across the network. Alpen is infrastructure for Bitcoin-native financial markets. Independent operators are a core part of its distributed architecture, validating and processing BTC flows without relying on a trusted majority.

With Testnet III, Alpen’s mainnet architecture is now operating in a public Bitcoin test environment and open to broader operator participation. Chainflow joins Alpen Labs and other operators in testing the Strata bridge’s 1-of-N trust model, under which the system remains secure as long as at least one operator acts honestly.

At the center of this architecture is Alpen’s Bitcoin verifier, which uses garbled circuits to verify BTC movement between Bitcoin and Alpen while preserving Bitcoin as the settlement layer for transactions occurring on Alpen. Chainflow will run node infrastructure and process user withdrawals. Its participation strengthens the operator set as Alpen progresses toward mainnet.

Testnet III marks the beginning of broader, independent participation in building Bitcoin-native financial infrastructure.

Alpen powers Bitcoin-native financial markets, secured by zero-knowledge proofs.
